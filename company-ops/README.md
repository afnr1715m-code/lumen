# نظام إدارة وتشغيل الشركة — عرض تجريبي (MVP)

نموذج أولي (Prototype/MVP) قابل للعرض على العميل لنظام إدارة وتشغيل شركة — يجمع بيانات التشغيل اليومي (المهام، الحضور، الخدمات، الإيرادات، التقارير)، يربطها ببعضها، ويولّد تنبيهات وتذكيرات تلقائية للمدير بدل ما يكون مجرد نظام إدخال بيانات.

هذا مشروع مستقل تمامًا، غير مرتبط بموقع Lumen التسويقي (lumen.com.sa) — لا يشترك معه بأي كود أو إعدادات.

## التقنيات المستخدمة

- **React 19 + TypeScript** — واجهة المستخدم
- **Vite** — أداة البناء والتطوير
- **Tailwind CSS v4** — التنسيق
- **React Router** — التنقل بين الصفحات
- **Zustand** — إدارة البيانات (قاعدة بيانات تجريبية في الذاكرة)
- **Recharts** — الرسوم البيانية
- **date-fns** — حسابات التاريخ
- **lucide-react** — الأيقونات

> لا يوجد Backend حقيقي — كل البيانات تجريبية (Mock Data) ومحفوظة في الذاكرة أثناء تشغيل المتصفح، وتُعاد للحالة الأصلية عند إعادة تحميل الصفحة (باستثناء تسجيل الدخول المحفوظ محليًا).

## متغيرات البيئة

لا يوجد. المشروع لا يتصل بأي خدمة خارجية أو API، وبالتالي لا حاجة لملف `.env`.

## التثبيت والتشغيل

يتطلب [Node.js](https://nodejs.org) نسخة 18 أو أحدث.

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل السيرفر المحلي (وضع التطوير)
npm run dev
```

بعدها افتحي الرابط اللي يظهر بالطرفية (عادة `http://localhost:5173`).

### أوامر أخرى

```bash
npm run build     # بناء نسخة الإنتاج داخل مجلد dist/
npm run preview   # معاينة نسخة الإنتاج المبنية محليًا
```

## حسابات الدخول التجريبية

بصفحة تسجيل الدخول، اضغطي على أي حساب من الحسابات الجاهزة لتسجيل الدخول مباشرة بدون كلمة مرور حقيقية:

| الاسم | الدور | ماذا يرى |
|---|---|---|
| منير العتيبي | مدير | كل الصفحات — لوحة المدير، الموظفون، الإيرادات، التقارير، سجل العمليات |
| سلطان الحربي | مشرف | تشغيل اليوم والخدمات والحضور لفريقه فقط |
| ريان المطيري | موظف | مهامه وحضوره الشخصي فقط |

## الصفحات والميزات

- **لوحة المدير** — مؤشرات أداء سريعة، تنبيهات مصنّفة (عاجل/يحتاج متابعة/قادم/مكتمل)، حالة الفرق الآن، رسم بياني للإيرادات، حالة التقارير، إجراءات سريعة
- **المهام** — عرض قائمة وعرض تقويم، بحث وفلترة وترتيب، إضافة/تعديل مهام بأولوية وتكرار
- **التقويم** — عرض يوم/أسبوع/شهر لكل المواعيد والمهام
- **الموظفون** — قائمة كاملة + صفحة تفصيلية لكل موظف (بياناته، عقده، إقامته، حضوره، مهامه)
- **الحضور والانصراف** — سجل يومي مع فلاتر حسب الفريق والموظف والتاريخ
- **الفرق** — قائمة الفرق + تفاصيل كل فريق (الأعضاء، الخدمات، الإيرادات، الحضور، التقارير)
- **تشغيل اليوم** — شاشة المشرف اليومية: بداية اليوم، تسجيل الخدمات أثناء اليوم، تقرير نهاية اليوم
- **الخدمات** — تسجيل خدمة لعميل، يحدّث دخل الفريق تلقائيًا
- **دخل الفرق** — مقارنة بين الفرق، فلاتر زمنية، تنبيه تلقائي عند وجود فرق بين قيمة الخدمة والمبلغ المحصّل
- **مركز التنبيهات** — كل التنبيهات التلقائية في مكان واحد
- **التقارير** — تقارير يومية/أسبوعية/شهرية مع رسم بياني وتصدير CSV حقيقي
- **بحث عام** — بحث فوري عن موظف/فريق/عميل/مهمة/خدمة (زر "بحث عام" بأعلى الصفحة)
- **سجل العمليات** — سجل زمني لكل الإجراءات المهمة داخل النظام

### التنبيهات التلقائية (Automation)

يُعاد حساب التنبيهات تلقائيًا (وليست بيانات ثابتة) من `src/lib/automation.ts` بناءً على البيانات الفعلية وتاريخ اليوم:

1. تقرير نهاية اليوم لم يُرفع
2. اقتراب/انتهاء عقد موظف
3. اقتراب/انتهاء إقامة موظف
4. وصول منتج للحد الأدنى من المخزون
5. اقتراب موعد استحقاق مهمة
6. فرق بين قيمة الخدمات والمبالغ المحصّلة
7. تذكير مراجعة الرواتب (يوم 20 لمنصة مدد، يوم 24 للعقود) — تذكير تجريبي فقط، وليس تكاملًا حقيقيًا مع أي منصة

## خارج نطاق هذا الـMVP

معروضة في الشريط الجانبي كـ"قريبًا" ولا تعمل فعليًا: نظام الرواتب الكامل، تكامل منصة مدد، تكامل واتساب، CRM متقدم، نظام محاسبي، ونظام مخزون متقدم (ERP).
